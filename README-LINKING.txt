ربط الصفحة الرئيسية بالصفحة الثانية
====================================

تم تعديل زر «سجّل الآن» في الواجهة الرئيسية ليذهب إلى:
./second-page/

هيكل الملفات المقترح على GitHub Pages:
/
├── index.html
├── styles.css
├── script.js
├── assets/                 ← احتفظ بمجلد assets الحالي في مشروعك
└── second-page/
    ├── index.html
    ├── styles.css
    ├── script.js
    └── tailwind-config.js

مهم:
- لا تغيّر اسم مجلد second-page إلا إذا عدلت الرابط في index.html أيضًا.
- ملفات assets غير مرفقة في هذه الحزمة؛ استخدم مجلد assets الموجود لديك أصلًا في المشروع.
- الصفحة الثانية تستخدم Tailwind CSS وGoogle Fonts عبر الإنترنت.

إصلاح الرابط المحلي: زر «سجّل الآن» يشير الآن مباشرة إلى ./second-page/index.html بدل المجلد فقط، حتى يعمل عند فتح الموقع محلياً وكذلك على GitHub Pages.

تعديل الشعارات الرسمية
======================
- تم استبدال مربعي «الشعار الأول / الشعار الثاني» بالشعارين الفعليين.
- شعار وزارة التربية والتعليم: assets/images/ministry-logo.png
- شعار مركز مسندم للثقافة والابتكار: assets/images/musandam-center-logo.png
- تم قص المساحات الشفافة الزائدة من نسخ الشعارات المستخدمة في الموقع حتى تظهر بحجم واضح ومتناسق.
- تم ضبط أحجام الشعارات تلقائيًا لسطح المكتب والهاتف في styles.css.


تعديل ترتيب الأقسام
===================
- تم نقل قسم «مسارات التعلم والابتكار» ليظهر مباشرة بعد قسم الإحصائيات «مسندم تبتكر».


إضافة قسم «مسابقات إضافية»
============================
- تمت إضافة القسم مباشرة بعد «رحلتك في المسابقة».
- يحتوي على 3 أزرار/روابط: 
  1) مسابقة التطبيقات المعززة بالذكاء الاصطناعي.
  2) مسابقة الأمن السيبراني لطلبة المدارس.
  3) للمزيد من المسابقات.
- لكل زر أيقونة مناسبة وتأثير Hover، والتصميم متجاوب مع الكمبيوتر والهاتف.
- الروابط الحالية مؤقتة على example.com حتى يتم تزويد الروابط الفعلية.
- لتغيير الروابط ابحث داخل index.html عن:
  https://example.com/ai-competition
  https://example.com/cybersecurity-competition
  https://example.com/more-competitions
- لتعديل تنسيق القسم ابحث داخل styles.css عن: [CSS-EXTRA-COMPETITIONS]

تحديث روابط المسابقات الإضافية
===============================
- تم ربط «مسابقة الأمن السيبراني لطلبة المدارس» بنفس رابط الخطة الإجرائية: ./second-page/index.html
- تم ربط «للمزيد من المسابقات» بنفس رابط الخطة الإجرائية: ./second-page/index.html
- تم جعل الرابطين داخليين في نفس الصفحة/التبويب، مثل زر «الخطة الإجرائية» في الواجهة الرئيسية.


تحسين بطاقات «مسابقات إضافية»
==============================
- تم تحويل البطاقات إلى تصميم أكثر وضوحًا واحترافية.
- البطاقة كاملة قابلة للضغط مع زر بصري واضح في أسفلها.
- تمت إضافة شارات، شريط لوني علوي، وحركات Hover/Focus.
- تم الحفاظ على الروابط الحالية دون تغيير.
- تم تحسين العرض المتجاوب للهواتف والأجهزة اللوحية.
- تم تصحيح وصف مسابقة الأمن السيبراني وإزالة علامة اقتباس زائدة.


تصغير أزرار الموقع
===================
- تم تصغير الارتفاع والحشو الداخلي للأزرار العامة لتبدو أكثر تناسبًا واحترافية.
- تم تصغير أزرار الواجهة الرئيسية مع الحفاظ على وضوح النص والأيقونات.
- تم تصغير أزرار بطاقات «مسابقات إضافية».
- تم ضبط نسخة الهاتف لتبقى الأزرار مدمجة دون أن تتحول إلى مساحات كبيرة.
- لم يتم تغيير الروابط أو وظائف JavaScript.
