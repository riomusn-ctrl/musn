تحديث بطاقات قسم «مسندم تبتكر»

تم تعديل البطاقات لتصبح زرقاء بنفس هوية الخط أسفل عنوان القسم، مع:
- خلفية زرقاء متدرجة وموحدة لجميع البطاقات.
- الأرقام باللون الأبيض لزيادة الوضوح.
- العناوين باللون الأبيض.
- الوصف الثانوي بأبيض شفاف مريح للقراءة.
- الأيقونات باللون الأبيض داخل دوائر شفافة.
- تحسين Hover والظل والشريط السفلي.

للاستخدام على GitHub Pages استبدل الملفات:
index.html
styles.css
script.js

وتأكد من بقاء مجلد assets كما هو في مشروعك الحالي.
