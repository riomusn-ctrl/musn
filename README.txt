إصلاح نهائي لصورة Hero على GitHub Pages

هذه النسخة لا تعتمد على أي مسار لصورة Hero.
تم تضمين صورة Hero نفسها داخل index.html بصيغة Data URI، لذلك لن تتأثر بـ:
- اسم مجلد assets
- اختلاف PNG / png
- الحروف الكبيرة والصغيرة
- نقل الصورة أو نسيان رفعها

طريقة الرفع:
1) فك الضغط.
2) ارفع index.html و styles.css و script.js و .nojekyll إلى نفس المجلد الذي تنشر منه GitHub Pages.
3) احتفظ بمجلد assets الموجود لديك لأن بقية صور الموقع ما زالت تستخدمه.
4) استبدل الملفات القديمة بهذه الملفات.
5) افتح الموقع ثم Ctrl + F5.

ملاحظة: حجم index.html أكبر من المعتاد لأن صورة Hero مضمنة داخله مباشرة. هذا مقصود لضمان ظهورها.
