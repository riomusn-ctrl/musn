منصة مسندم للابتكار والمسابقات العلمية 2026–2027
===================================================

الملفات:
- index.html       الصفحة الرئيسية
- styles.css       التصميم والألوان والاستجابة
- script.js        التفاعلات البسيطة
- assets/images/   مكان الصور
- assets/videos/   مكان الفيديو

طريقة التشغيل:
1) افتح مجلد المشروع.
2) افتح index.html مباشرة في المتصفح، أو استخدم Live Server داخل VS Code.
3) عند رفعه على استضافة، ارفع المجلد كاملًا مع الحفاظ على نفس بنية الملفات.

مهم:
المشروع الحالي Static Frontend احترافي للمرحلة الأولى.
عند تحويله إلى Full-Stack:
- يفضل تقسيمه إلى React Components.
- نقل البيانات إلى قاعدة PostgreSQL.
- ربط التسجيل وCRUD بالـ Backend.
- ربط المرشد الذكي بـ POST /api/assistant/chat.
- استخدام Object/App Storage للصور والفيديو وملفات PDF.
